Week 2: JavaScript Introduction

This page demonstrates the basics of JavaScript. Open the browser console to see the output of each example.

What is console.log?

console.log() is a function in JavaScript that prints messages to the browser's console. It's commonly used for debugging and viewing output while learning or developing code. 

console.log("Hello, world!");

To see the output, right-click the page, choose "Inspect" or "Inspect Element", and open the "Console" tab.

Data Types Example

JavaScript has several data types to represent different kinds of values.

let age = 25; // Number
let name = "Matías"; // String
let isStudent = true; // Boolean
let nothing = null; // Null
let notDefined; // Undefined
let person = { name: "Matías", age: 25 }; // Object
let skills = ["HTML", "CSS", "JavaScript"]; // Array

Variables Example

Variables are containers for storing data values. Use let for variables that can be reassigned and const for constants. 

let city = "New York";
const PI = 3.14159;
var oldWay = "Avoid using var";

Operators Example

Operators are used to perform operations on variables and values.

let a = 5, b = 3;
console.log(a + b); // 8
console.log(a == b); // false

Loops Example

Loops can execute a block of code a number of times.

for (let i = 0; i < 5; i++) {
  console.log(i);
}

Functions Example

Functions are blocks of code designed to perform a particular task.

function greet(name) {
  return "Hello, " + name + "!";
}
console.log(greet("Matías"));
