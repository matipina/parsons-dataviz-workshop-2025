Modern JavaScript Concepts for D3.js

A quick review of Arrow Functions, Maps, and Async/Await.

1. Arrow Functions (=>)

A concise way to write functions in JavaScript. They are especially useful for short, anonymous functions used in D3 methods.


        


        

            
2. Map Objects

            
A `Map` holds key-value pairs and remembers the original insertion order of the keys. D3's `d3.group()` and `d3.rollup()` return Maps.

            

                
            

            

        


        

            
3. Async/Await

            
A modern way to handle asynchronous operations, like loading data. It makes asynchronous code look and behave more like synchronous code, making it easier to read and write.
